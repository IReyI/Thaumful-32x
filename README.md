# Thaumful 32x

**A Faithful-style 32× resource pack for Thaumcraft 4 Reforged.**

Thaumful 32x brings a more detailed, Faithful-inspired visual style to Thaumcraft, aiming to preserve Minecraft's familiar aesthetic while enhancing the look of magical blocks, items, and other modded textures.

## ✨ Features

- **32× resolution** for more detailed textures.
- **Faithful-inspired style** that stays close to Minecraft's recognizable visual identity.
- **Designed for Thaumcraft 4 Reforged.**

Thaumful 32x is designed for **Thaumcraft 4 Reforged**.

Install the mod version compatible with your Minecraft installation before enabling the resource pack.

## 🛠️ Installation

1. Download the ZIP file from [GitHub Releases](https://github.com/IReyI/Thaumful-32x/releases).
2. Launch Minecraft: Java Edition.
3. Open **Options → Resource Packs → Open Pack Folder**.
4. Move the downloaded ZIP file into the resource packs folder.
5. Return to Minecraft and enable **Thaumful 32x**.
6. If you use other resource packs, adjust their order if necessary.

## ⚙️ Compatibility

- **Edition:** Minecraft: Java Edition
- **Target mod:** [Thaumcraft 4 Reforged](https://github.com/notlikethiss/thaumcraft-4-reforged)
- **Texture resolution:** 32×32

Compatibility with other Minecraft versions, mod loaders, or Thaumcraft ports is not guaranteed.
