# Thaumful 32x

**A Faithful-inspired 32× resource pack for Thaumcraft 4 Reforged.**

Thaumful 32x brings the familiar Faithful visual style to Thaumcraft, adapting the resource pack's structure and texture filenames to work with the mod's resource-loading system.

The project builds upon textures from [Faithful 32 Modded Edition for Minecraft 1.7.10](https://github.com/F32Organization/Faithful32-1.7.10), with technical adaptations and further texture work planned.

---

## ✨ Features

- **Faithful-inspired visuals** — preserves the familiar look of Faithful's 32× textures.
- **Resource compatibility adaptations** — reorganized the resource pack structure to support the resource-loading system used by the target environment.
- **Correct texture identifiers** — renamed selected texture files to match the names expected by the mod.
- **Ongoing development** — additional textures and improvements are planned.

## 🎨 Project Goals

The goal of Thaumful 32x is to provide a consistent Faithful-style visual experience for Thaumcraft 4 Reforged.

Development focuses on:

- Adapting existing textures to the target mod.
- Creating missing textures where needed.
- Maintaining a consistent 32× visual style.
- Improving compatibility and correcting missing or incorrectly loaded textures.

## 🛠️ Installation

1. Download the desired Thaumful 32x release.
2. Locate your Minecraft resource packs directory.
3. Place the downloaded resource pack archive in the `resourcepacks` folder, unless the release instructions specify otherwise.
4. Launch Minecraft and open **Options → Resource Packs**.
5. Enable Thaumful 32x.

If the pack does not appear or some textures are missing, check that the archive contains `pack.mcmeta`, `pack.png` (if included), and the `assets` directory at the expected level.

## 🔧 Technical Contributions

The following changes have been made specifically for Thaumful 32x:

- **Resource pack structure:** reorganized to address incompatibilities with the updated resource-loading system.
- **Texture filenames:** renamed selected files to match the identifiers expected by the mod.
- **Texture development:** additional textures and fixes are planned as development continues.

These adaptations help the resource pack load the intended assets in the target environment. They do not imply that the underlying Faithful textures were originally created for this project.

## 🧪 Compatibility and Testing

Thaumful 32x is intended for use with **Thaumcraft 4 Reforged**.

Compatibility depends on the Minecraft version, mod version, and resource-loading implementation. Check the release notes and test the pack in your specific setup.

If you encounter a missing or incorrectly displayed texture, please include:

- Minecraft version.
- [Thaumcraft 4 Reforged version](https://github.com/notlikethiss/thaumcraft-4-reforged).
- Resource pack version.
- A screenshot of the affected texture, if possible.
- Relevant log output, if available.
